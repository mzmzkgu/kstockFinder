# 종목파인더 (kstockFinder)

거래량·흐름·AI 분석을 종합해 매일 TOP 3 추천 종목을 보여주는 한국 주식 대시보드.

## 구성
- `index.html` — 오늘의 추천 / 최근 추천 기록 2개 탭으로 구성된 페이지
- `index_1.html`, `index_2.html` — 이전 버전 스냅샷

## 주요 기능
- 추천 종목별 AI 코멘트, 장점/단점, 권장 보유기간, 최근 20일 상대 수익률 비교 차트
- 추천 기록(날짜별) 조회 및 실제 수익률 추적
- 장 시작 직후(09:10) 미국 시장(나스닥/S&amp;P500)·코스피 등락과 추천 종목 갭을 보여주는 "오늘 진입 신호" 카드
- 백엔드: `kgu3405.tplinkdns.com/api/kstockfinder` (`/top3`, `/history`, `/signal`)
- 투자 손실 위험에 대한 디스클레이머 포함
